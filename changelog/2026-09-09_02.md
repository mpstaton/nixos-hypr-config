# A Broken Alias, and the Tools Agents Reach For

## Why Care?

`home.nix` has aliased `grep` to `ugrep --color=auto` for as long as it has
existed. ugrep was never installed. So every interactive `grep` was a
command-not-found, and the fix was one line in a package list.

That is a small thing. What made it worth a changelog is the pattern it belongs
to: **a missing small tool rarely announces itself.** It shows up as a script
behaving oddly, an agent taking a strange detour, or — worst — as nothing at
all, while something downstream quietly does the wrong thing.

## The expensive version of the same problem

Neither `lsof` nor `fuser` was installed on this machine.

Practically every script that needs "which process holds port 4402" reaches for
one of them. When neither exists, the lookup returns nothing, the script carries
on, and Astro's preview server — which silently auto-increments past a busy port
rather than failing — lands on a different port than requested. A harness built
to serve three site variants side by side then served the wrong builds under the
right labels, twice, before anyone suspected the cause was `lsof: command not
found`.

That is the whole argument for installing these. The cost of having them is
nil. The cost of not having them is a debugging session that never mentions the
real cause.

## What got installed

`home/mps/dev-tools.nix`, imported from `home.nix` in the same way
`gaming.nix` is imported from `configuration.nix`.

**Search** — `ripgrep` moved here from `home.nix` so it sits next to `ugrep`,
and the choice between them is documented in the file: rg for everyday work
because it respects `.gitignore` (which matters in a tree full of
`node_modules`), ugrep when the search is a question rather than a pattern —
boolean queries, fuzzy matching, searching inside archives and PDFs.

**Process and port inspection** — `lsof`, `psmisc` (fuser, killall, pstree).
The silent-failure class above.

**Reflex tools** — `sqlite`, `zip`, `dnsutils` (dig), `xxd`, `file`, `entr`,
`just`. Each is the obvious tool for a job that comes up often enough that
working around its absence costs more than installing it.

**Git and shell** — `delta` (with `programs.delta.enableGitIntegration`, so git
actually calls it), `aha`, `duf`, `yq`.

**`direnv` + `nix-direnv`**, which is the one that changes the daily rhythm —
see below.

The whole set is about 41 MB, and roughly half of that is three packages.
`aha` and `entr` are 39 KB each. Everything came prebuilt from
`cache.nixos.org`, which is why the switch appeared to install nothing: there
was nothing to compile and nothing to download.

## What did NOT get installed, and why

Sixteen other commonly-suggested tools were left out: `sd`, `dust`, `procs`,
`difft`, `tokei`, `hyperfine`, `jless`, `gron`, `mlr`, `httpie` and similar.
Each duplicates something already here — `sd` against sed, `dust` against duf,
`procs` against htop, `difft` against delta.

That restraint is deliberate and was learned the hard way an hour earlier. The
lossless-monorepo flake had accumulated a devshell that tried to mirror a whole
macOS setup — terminal emulators, GUI editors, a Rust toolchain — and became so
slow to enter that it went unused, which is why these gaps went unnoticed in the
first place. A tools list earns its place by being reached for, not by being
comprehensive.

`gcc` and `make` are also absent, and their absence does break `node-gyp`
native builds. That is left alone on purpose: a C toolchain in a user profile
is a larger decision than a CLI utility, and the idiomatic NixOS answer is a
devshell.

## direnv, and what it unlocks

direnv has to be on `PATH` *before* you enter a directory in order to auto-load
anything, so it can never be shipped inside the devshell it is meant to launch.
It has to be installed permanently. Now that it is, the monorepo's
`.envrc.local` opt-in works, and `cd`-ing into that tree provides node, pnpm,
bun, deno and typescript with nothing typed.

That opt-in was also retargeted from the tree's `default` shell to its `.#js`
shell. `default` builds a Rust toolchain — precisely what should not fire
automatically on every `cd`.

## Two deprecations cleared

The first switch warned that `programs.git.delta.enable` is now
`programs.delta.enable`, and that `enableGitIntegration` no longer enables
itself implicitly. Both are stated explicitly now, which also makes the
two-part setup legible: install the pager, then tell git to use it.
